CN-03: Weak Locks

CryptographyModerate

The maintenance note from CN-02 held an encoded configuration string. CeylonGov Secure's legacy tooling protected it with a weak, layered scheme. Recover the plaintext to get this stage's flag and the credentials for the evidence archive.

How to start

Goal: Decode the string in challenge.txt to get the flag and the CN-04 login.

  1. Download challenge.txt and copy the encoded string.
  2. The first layer is an encoding, the second is a classic cipher that needs a keyword. The keyword was in the CN-02 maintenance notes.
  3. Use CyberChef (From Base64, then Vigenere Decode) or write a short Python script.
  4. The result contains the flag and a username and password. Keep the username and password for CN-04.
