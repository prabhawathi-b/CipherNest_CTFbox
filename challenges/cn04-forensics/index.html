CN-04: Buried Logs

Digital ForensicsModerate

The credentials from CN-03 unlocked this evidence archive. It holds a snapshot captured from the compromised staging server. Work out which internal host the intruder moved to next.

How to start

Goal: Find which internal host the intruder moved to next.

  1. Click Download below. Your browser will ask for a username and password. This is expected: use the login you recovered in CN-03. No login yet? Solve CN-03 first.
  2. Open the downloaded file with a tool that reads raw bytes, for example strings, grep or a hex editor.
  3. Two logs are readable straight away. Look for an IP address that appears again and again.
  4. Part of the file is not visible when you read it normally. Search the raw bytes for markers to recover it. The recovered note holds the flag and the internal host for CN-05.
